# PinCreator

Небольшое локальное приложение для демонстрации конвейера:

`CSV → метаданные OpenAI → изображения OpenAI → ImageKit → result.csv`

Проект распространяется по лицензии MIT. API-ключи хранятся только в локальном
файле `.env`, который исключён из Git. Для публикации используется безопасный
шаблон `.env.example` без реальных значений.

## Быстрый старт

1. Установите Python 3.11 или новее.
2. Дважды нажмите `install.bat` — он создаст виртуальное окружение и установит зависимости.
3. Дважды нажмите `run.bat`, чтобы открыть PinCreator.
4. На вкладке **Settings** укажите OpenAI API key, выберите (или впишите) модели и
   добавьте ImageKit private key и URL endpoint.
5. Выберите CSV и нажмите **Start**.

Альтернативный ручной запуск:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   python app.py
   ```

Для знакомства с форматом используйте `sample_input.csv` и `example_prompt.txt`.

## Входной CSV

| Колонка | Значение |
|---|---|
| `count` | Сколько пинов создать для этой строки |
| `keywords` | Ключевые слова через запятую |
| `prompt_file` | Путь к локальному TXT-файлу с мастер-промптом |

Можно добавить несколько строк — приложение объединит все задания в один запуск.

TXT-файл является мастер-промптом для текстовой модели и должен содержать две переменные:

- `{{COUNT}}` — программа подставит количество записей в текущей пачке (обычно 10);
- `{{KEYWORDS}}` — программа подставит ключевые слова из CSV.

Для каждой строки CSV текстовые задания создаются пачками по 10. Например, 100 пинов — это
10 последовательных запросов по 10 записей. Каждый запрос получает тот же мастер-промпт и
ключевые слова, а также номер пачки и заголовки из предыдущих пачек для снижения повторов.
После завершения всех пачек приложение сохраняет полный набор в `tasks.csv` и только затем
начинает последовательно генерировать изображения.

## Результат

Каждый запуск создаёт отдельную папку `output/YYYYMMDD_HHMMSS/`:

- `tasks.csv` — промежуточный файл с ID, title, description и image prompt;
- `images/` — локальные PNG;
- `result.csv` — ID, URL из ImageKit, title и description.

`result.csv` перезаписывается после каждого успешно загруженного изображения, поэтому уже
готовые строки не пропадут при сетевой ошибке. Файл `.env` содержит секреты и исключён из Git.

## Важно

- Генерация изображений и текстов расходует API-баланс OpenAI.
- Изображения генерируются моделью `gpt-image-2` с фиксированным `quality=low`.
- ImageKit private key предназначен только для локального использования. Не публикуйте `.env`.
- Перед большим запуском проверьте настройки на 1–3 пинах.
